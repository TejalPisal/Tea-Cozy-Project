# 🫖 Tea Cozy Website

## 📋 Overview  
The **Tea Cozy Website** is a responsive landing page built using **HTML** and **CSS**. It showcases a fictional tea shop, highlighting its mission, featured teas, and store locations. The goal of this project was to practice semantic HTML structure and modern CSS styling for layout and design consistency.

## 🛠️ Technologies Used  
- HTML5  
- CSS3  
- Flexbox  

## 🎯 Features  
- Fully responsive design  
- Structured and semantic HTML elements  
- Organized layout using Flexbox  
- Clean and minimal design aesthetic  

## 💡 What I Learned  
- Building a webpage layout using **Flexbox**  
- Creating responsive designs without frameworks  
- Structuring HTML for readability and accessibility
